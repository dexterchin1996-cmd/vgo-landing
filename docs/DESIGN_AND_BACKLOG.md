# VGO 3.0 设计与遗留需求专项台账

本文件专门记录平台在“视觉设计、体验优化、工具选型、以及尚未开发的功能”方面的全部规划。

## 第一部分：设计理念与视觉标准
- **总体目标**：摒弃 2.x 的陈旧感，采用 2026 年最新、最流行的商业营销风格（Cinematic / 沉浸式）。
- **视觉要求**：高级感、高转化率、吸引客户注意力，明确传达“VGO能解决什么问题”。
- **交互动效**：滚动视差（Parallax）、毛玻璃（Glassmorphism）、骨架屏、首屏（Hero）震撼动效。

## 第二部分：工具与设计系统选型
- **设计资产工具**：已整合 `toolkit/` 下的参考文档（包含 Facebook/腾讯等 UI 规范）。
- **AI 代码/结构地图工具**：计划引入（如 `ai-code-compass`），用于后续快速梳理复杂组件依赖（原登记 R2）。
- **组件库体系**：基于 Tailwind v4 建立原子化 Design Tokens，统一 Button/Card/Badge 风格。

## 第三部分：尚未开发的功能清单（没打给的遗留项）
1. **招募页表单闭环 (R13)**：
   - 现状：目前只有静态展示和 FAQ。
   - 待办：需开发真实的“商家/师傅入驻申请表单”，并接入 API 存入数据库。
2. **后台控制官网 (前后端联动)**：
   - 现状：官网目前是纯展示，文字写死在代码里。
   - 待办：开发 `vgo-service` (Hub 后台) 与 `vgo-server` 的接口，实现通过后台动态修改官网公告、活动、轮播图。
3. **多语言意境本地化 (T38)**：
   - 现状：马来文是 AI 直译，缺乏商业营销的“灵魂”。
   - 待办：对接本地化工具（Weblate/DeepL API）或人工，重写商业级马来文文案。

## 第四部分：视觉内容素材
- 确认官网所需的高质量场景图（维修、清洁、按摩等）已具备商业授权。
- 确保 `public/assets` 下的动效音效和图标符合最新设计规范。
