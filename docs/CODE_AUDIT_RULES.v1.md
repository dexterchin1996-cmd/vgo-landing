# 代码审计规则（CA 系列）

**建立：** 2026-10-18
**规则：** 任何删除/归档/合并动作前，必须先读本文件并引用规则编号。

## CA-1 零引用 ≠ 无用
归档前必须查 6 种隐形使用：
1. 动态导入 import() / require()
2. React.lazy / next/dynamic
3. 配置/JSON 驱动（组件名写在配置数组里）
4. 全项目字符串提及（docs/scripts/根配置/.md/.json）
5. 大小写变体引用
6. 测试/Storybook/文档入口

## CA-2 归档不删除
用 git mv 移入 _archive/，保留 git 历史，可回滚。

## CA-3 归档前取证
大小、行数、最后修改、git 最近提交、全部引用来源，缺一不可。

## CA-4 近似名必须查双方
一活一死要标记；两活要查是否重复实现。

## CA-5 执行前必须有回滚路径
写进命令或台账。

## CA-6 审计输出必须可复现
命令 + 终端输出，不靠口头结论。

## CA-7 不确定的保留并登记
不猜、不赌。

## CA-8 审计结论引用规则编号
证明按规则执行。
