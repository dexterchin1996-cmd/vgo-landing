# VGO 3.0 平台总规划与交付手册

## 第一部分：平台架构与范围定义
VGO 平台已确认为 7 个独立部署单元：
1. 后端 API (server/) - Fastify + Supabase
2. 官网 (website/) - Next.js 15
3. 客户端 App (vgo-service mode=customer)
4. 商家端 App (mode=merchant)
5. 师傅端 App (mode=tech)
6. 运营后台主控台 (mode=hub) - 桌面端
7. 运营移动台 (mode=mobile-hub) - 手机端

## 第二部分：工程基线验收报告 (截至 2026-10-18)
1. 多仓库独立化：4 个核心仓库全部独立并推送远程。
2. 部署打通：修复 45 个 ESLint 阻断错误，移除 WASM 依赖，升级 Next.js 15.5.7 绕过安全拦截，Vercel 构建成功。
3. 国际化重构：拆分 TRANSLATIONS，打通服务端 generateMetadata，实现三语 (中/英/马) SEO 标签动态生效。
4. 安全与资产：7 个密钥双层 AES-256 加密；修复 5 处 OTP/PIN 伪随机数漏洞。
5. 规范沉淀：建立 PC-2 执行清单、CA 审计规则、KP 故障知识库。

## 第四部分：强制工程规范 (摘要)
1. D9 核心规矩：终端输出是唯一事实来源，台账只是记录。
2. CA-1 规则：零引用不等于无用。归档前必须查清 7 种隐形使用。
3. PC-2 执行清单：任何删除/归档动作前，必须先查引用、dry-run、确认可回滚。
4. KP-9 限制：Termux 仅用于开发与 tsc 验证，禁止在手机本地跑 next build 或 dev server。
