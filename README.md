# VGO Malaysia · 官网

## 快速开始
    cd ~/vgo-dev/vgo-landing
    NODE_OPTIONS=--max-old-space-size=1024 nohup npm run dev > dev.log 2>&1 &

## 技术栈

三语：中 / EN / BM（自动识别）

    src/components/    导航/弹窗/板块组件
    src/data/waitlist.ts   注册数据
    src/lib/i18n.tsx       三语
